# 📊 Sales Analytics Dashboard

## 📌 Project Overview

The **Sales Analytics Dashboard** is an interactive dashboard designed to analyze and monitor sales performance. It provides a clear overview of revenue, orders, customers, products, regional performance, and sales trends.

## 🎯 Objectives

* Track overall sales performance
* Analyze monthly sales trends
* Compare sales and profit across regions
* Identify top customers
* Analyze product and category performance
* Monitor order trends
* Provide quick and clear business insights

## 📈 Key KPIs

* **Total Revenue**
* **Total Quantity Sold**
* **Total Orders**
* **Average Order Value**
* **Total Customers**

## 📊 Dashboard Analysis

The dashboard includes:

* Monthly Sales Trend
* Sales by Region
* Profit by Region
* Top 5 Customers by Revenue
* Sales vs Cost by Product
* Sales by Item Category
* Quantity Sold by Product
* Orders Over Time

## 🔎 Filters

The dashboard includes filters that allow users to explore the data based on different categories and periods.

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Visualization
* Dashboard Design

## 💡 Key Insights

This dashboard helps users quickly understand sales performance, identify high-performing regions and products, analyze customer contribution, and monitor changes in sales and orders over time.
